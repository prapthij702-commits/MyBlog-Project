# My Blog Application

A simple Blog Application built using:

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MySQL

## Features
- User Registration
- User Login
- Create Blog Posts
- View Blog Posts
- Edit Blog Posts
- Delete Blog Posts

## How to Run

1. Install dependencies using npm install.
2. Configure your backend .env file.
3. Start the backend using node server.js.
4. Open frontend/index.html using Live Server.
